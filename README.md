# Talks

Slide decks of talks by Johann Glock, written with [Slidev](https://sli.dev). The slides of each talk are on [glockyco.com/talks](https://glockyco.com/talks/) as a PDF.

| Talk | Event | Folder |
| --- | --- | --- |
| [Formal Guarantees Meet Practical Constraints](https://glockyco.com/talks/2026-11-17-phd-seminar/) | SCCH PhD Seminar, 17 November 2026 | [2026-11-17-phd-seminar](2026-11-17-phd-seminar) |

## Build a deck

Each folder is a deck of its own. You need Node.js and pnpm:

```sh
cd 2026-11-17-phd-seminar
pnpm install
pnpm dev
```

The folder's `AGENTS.md` lists its other commands, such as the PDF export.
